# BillionBank - Banking Application

## About the Project

BillionBank is a banking application I developed to practise my programming skills and gain more experience with C#.

The project focuses on simulating basic banking operations while improving my understanding of application development, programming logic and user interaction.

## Technologies Used

- C#
- .NET
- Visual Studio

## Project Features

The application focuses on basic banking functionality, such as:

- Managing bank accounts
- Handling banking transactions
- Tracking account balances
- Processing user input

## What I Learned

Working on BillionBank helped me improve my understanding of:

- Object-oriented programming
- Working with methods and classes
- Handling user input and validation
- Debugging and fixing errors
- Structuring and organising code

## Future Improvements

Some features I would like to explore in future versions include:

- Database integration
- Improved security and authentication
- A more modern user interface
- Additional banking features
